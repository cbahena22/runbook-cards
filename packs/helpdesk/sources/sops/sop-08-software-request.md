# SOP: Install extra software on request
related: sop-02-new-starter-laptop

Purpose: install extra software on request.

Steps
1. Check the software is on the approved list.
2) If it is not, send the request to the desk manager.
Step 3: Check the licence count.
4. Push the package from the software centre.
5) Ask the user to confirm it starts.
Step 6: Update the licence sheet.

Check: Software is on the approved list; licence sheet updated.
Escalate to: Desk manager

Use 'Sw Req' form (old name).
