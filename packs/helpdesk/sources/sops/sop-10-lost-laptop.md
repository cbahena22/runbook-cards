# SOP: A laptop is reported lost or stolen
related: sop-04-mfa-device-lost

Purpose: a laptop is reported lost or stolen.

Steps
1) Get the time and place the laptop was last seen.
Step 2: Disable the user's sessions in the directory console.
3. Mark the device as lost in the device manager.
4) Start a remote lock if the laptop is online.
Step 5: Tell the security desk straight away.
6. Raise a ticket for a replacement laptop.

Check: Sessions revoked; device flagged as lost.
Escalate to: Security desk
