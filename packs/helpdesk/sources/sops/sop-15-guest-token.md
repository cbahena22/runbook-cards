# SOP: Issue a guest hardware token
related: sop-09-guest-wifi

Purpose: issue a guest hardware token.

Steps
1) Check the visitor is on the reception list.
Step 2: Take a spare token from the safe.
3. Register the token to the visitor in the token console.
4) Write the token number in the visitor log.
Step 5: Collect the token when the visitor leaves.

Check: Token number is in the visitor log.
Escalate to: Reception lead
