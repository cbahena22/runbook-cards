# SOP: Give someone access to a shared mailbox
related: sop-01-password-reset

Purpose: give someone access to a shared mailbox.

Steps
1) Check the ticket has the mailbox owner's approval.
Step 2: Open the mail admin console.
3. Add the user with Full access to the mailbox.
4) Wait up to 30 minutes for the mailbox to show in the client.
Step 5: Tell the user how to open it.
6. Record the approval in the ticket.

Check: Approval is attached to the ticket; the user appears in the access list.
Escalate to: Mailbox owner

Mixed: some old tickets used 'delegate', same thing.
