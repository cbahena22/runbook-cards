# SOP: Prepare a laptop for a new starter
related: sop-01-password-reset

Purpose: prepare a laptop for a new starter.

Steps
Step 1: Pick a laptop from the shelf marked READY.
2. Run the imaging task from the deployment console.
3) Join the device to the company domain.
Step 4: Create the user's mailbox from the starter ticket.
5. Install the standard software bundle.
6) Label the laptop with the asset tag and hand over.

Check: Asset tag matches the inventory sheet; disk encryption shows as on.
Escalate to: Desk manager

Note: ask facilities about the docking station, not us.
