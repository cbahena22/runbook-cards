# SOP: Give a visitor guest wifi
related: sop-12-meeting-room-display

Purpose: give a visitor guest wifi.

Steps
1. Get the visitor's name and host from reception.
2) Create a guest voucher in the wireless console.
Step 3: Set the voucher to expire at the end of the day.
4. Give the voucher code to reception.
5) Remind the visitor that guest wifi has no access to internal systems.

Check: Voucher shows the right expiry date.
Escalate to: Reception lead
