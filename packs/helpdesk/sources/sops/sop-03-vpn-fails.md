# SOP: VPN will not connect
related: sop-04-mfa-device-lost

Purpose: vpn will not connect.

Steps
Step 1: Ask whether other websites work on the user's home network.
2. Check that the user's account is not locked.
3) Ask the user to restart the VPN client.
Step 4: Reinstall the VPN client from the software centre.
5. Check the time on the laptop is correct.
6) If it still fails, send the client log to the network team.

Check: Account unlocked; client version is the current one; clock is within a minute.
Escalate to: Network team

Old note: use the OldSIEM dashboard to see failed logons (retired).
