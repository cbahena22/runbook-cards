# SOP: Printer queue is stuck
related: sop-12-meeting-room-display

Purpose: printer queue is stuck.

Steps
1. Check the printer shows ready on its own screen.
2) Open the print server console.
Step 3: Cancel all jobs for that printer.
4. Restart the print spooler service.
5) Send a test page.
Step 6: If the test page fails, power cycle the printer.

Check: Test page printed; queue shows zero jobs.
Escalate to: Facilities
