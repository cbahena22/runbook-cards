# SOP: User lost the phone that holds their MFA app
related: sop-01-password-reset

Purpose: user lost the phone that holds their mfa app.

Steps
Step 1: Confirm the identity of the caller with a manager.
2. Disable the old MFA device in the directory console.
3) Issue a temporary access pass valid for one hour.
Step 4: Ask the user to register the new phone.
5. Close the old device record.
6) Tell the security desk about the lost phone.

Check: Old device shows as removed; the temporary pass has expired after use.
Escalate to: Security desk
