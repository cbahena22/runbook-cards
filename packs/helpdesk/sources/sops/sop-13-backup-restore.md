# SOP: Restore a file from backup
related: sop-07-leaver-account

Purpose: restore a file from backup.

Steps
1) Get the exact file path and the date it was last good.
Step 2: Check the requester owns the file or has the owner's approval.
3. Open the backup console and find the snapshot.
4) Restore to a temporary folder, never over the original.
Step 5: Tell the requester where to find it.
6. Delete the temporary copy after 7 days.

Check: Approval recorded; restore went to a temporary folder.
Escalate to: Backup owner
