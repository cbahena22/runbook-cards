# SOP: Laptop disk space is low
related: sop-08-software-request

Purpose: laptop disk space is low.

Steps
1) Open the disk usage view on the laptop.
Step 2: Empty the recycle bin and the downloads folder with the user.
3. Run the disk clean-up tool.
4) Check the user's mailbox cache size.
Step 5: If still low, plan a laptop swap.

Check: Free space is above 15 percent.
Escalate to: Desk manager

Short one.
